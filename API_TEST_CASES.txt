1. POST /api/v1/media/process (Aliases: /video/process, /video/jobs)
--------------------------------------------------------------------------------
Dùng để: Tải video/audio từ URL (YouTube, TikTok, Facebook,...), nén/transcode video,
         bóc tách âm thanh sang MP3/WAV/AAC, hoặc chụp thumbnail từ video.
Content-Type: multipart/form-data (hoặc application/json nếu không upload file)

CÁC PARAMS CẤP ĐẦU (Form fields):
* file: [File nhị phân] (Tùy chọn nếu có url hoặc input_key). Hỗ trợ: mp4, mkv, webm, avi, mov, flv, wmv, mp3, wav, flac, aac, m4a, ogg.
* input_file_key (hoặc input_key): [string] (Tùy chọn) Key file đã có sẵn trên R2, ví dụ: "uploads/{job_id}/original.mp4".
* url: [string] (Tùy chọn) URL video từ YouTube, TikTok, Facebook, Instagram,...
* operation: [string] (Mặc định: "transcode"). Các giá trị hợp lệ:
    - "url_download" (hoặc "download", "ytdlp"): Tải media từ URL.
    - "transcode": Nén / đổi định dạng / đổi codec video.
    - "extract-audio" (hoặc "audio"): Bóc tách âm thanh từ video sang audio file.
    - "thumbnail": Chụp 1 ảnh khung hình tại thời điểm bất kỳ trong video.
* params (hoặc options): [JSON string hoặc object] Các tùy chọn chi tiết:
    + Khi operation = "url_download":
        - "format": "mp4" (video), "mp3" (audio), "wav", "aac", "m4a" (Mặc định: "mp4")
    + Khi operation = "transcode":
        - "format": "mp4", "mkv", "webm", "avi" (Mặc định: "mp4")
        - "vcodec": "libx264" (H.264), "libx265" (HEVC/H.265), "libvpx-vp9", "copy" (Mặc định: "libx264")
        - "acodec": "aac", "libmp3lame", "opus", "copy" (Mặc định: "aac")
        - "crf": "18" (chất lượng rất nét), "23" (chuẩn mặc định), "28" (nén giảm dung lượng cao)
    + Khi operation = "extract-audio":
        - "format": "mp3", "wav", "aac", "ogg", "flac", "m4a" (Mặc định: "mp3")
    + Khi operation = "thumbnail":
        - "time": Thời điểm lấy ảnh, định dạng "HH:MM:SS" hoặc số giây, ví dụ: "00:00:05", "00:01:30", "5" (Mặc định: "00:00:01")

2. POST /api/v1/image/process
--------------------------------------------------------------------------------
Dùng để: Nén ảnh, thay đổi kích thước, cắt cúp (crop), hoặc xóa phông nền bằng AI.
Content-Type: multipart/form-data (hoặc application/json nếu đã có input_key)

CÁC PARAMS CẤP ĐẦU (Form fields):
* file: [File nhị phân] (Tùy chọn nếu có input_key). Hỗ trợ: png, jpg, jpeg, webp, bmp, tiff, gif.
* input_key: [string] (Tùy chọn) Key file ảnh có sẵn trên R2.
* operation: [string] (Mặc định: "compress"). Các giá trị hợp lệ:
    - "compress": Nén dung lượng ảnh.
    - "resize": Đổi kích thước ảnh (width / height).
    - "crop": Cắt cúp ảnh theo tọa độ box.
    - "remove_background": Tách phông nền bằng AI BiRefNet (tự động chạy qua GPU worker).
* options: [JSON string hoặc object] Các tùy chọn chi tiết:
    + Khi operation = "compress":
        - "quality": [int, 1-100] Mức chất lượng nén (Mặc định: 85).
        - "format": "JPEG", "PNG", "WEBP" (Chuyển sang định dạng đích nếu muốn).
        - "lossless": [bool, true/false] (Chỉ áp dụng với WEBP, mặc định: false).
    + Khi operation = "resize":
        - "width": [int] Chiều rộng mới theo px (ví dụ: 800).
        - "height": [int] Chiều cao mới theo px (ví dụ: 600).
          (Lưu ý: Nếu chỉ truyền width hoặc height, hệ thống tự động giữ nguyên tỉ lệ aspect-ratio).
        - "quality": [int, 1-100] (Tùy chọn, mặc định: 85).
    + Khi operation = "crop":
        - "box": [array gồm 4 số int: [left, upper, right, lower]], ví dụ: [100, 100, 500, 500].
        - "quality": [int, 1-100] (Tùy chọn, mặc định: 85).
    + Khi operation = "remove_background":
        - Không cần options (output luôn là file PNG trong suốt).

3. POST /api/v1/convert-file (Alias: /api/v1/convert)
--------------------------------------------------------------------------------
Dùng để: Chuyển đổi định dạng file văn bản, bảng tính, vector hóa và ảnh.
Content-Type: multipart/form-data

CÁC PARAMS CẤP ĐẦU (Form fields):
* file: [File nhị phân] File tài liệu hoặc hình ảnh nguồn.
* input_key: [string] (Tùy chọn nếu không upload trực tiếp). Key trên R2.
* to: [string] (BẮT BUỘC) Định dạng đích mong muốn.
    - Chuyển tài liệu: "pdf", "docx", "doc", "csv", "json".
    - Chuyển vector/ảnh: "svg", "png", "jpg", "jpeg", "webp".
* from (alias: from_format): [string] (TÙY CHỌN, server tự động nhận diện từ MIME/signature):
    CÁC CẶP CHUYỂN ĐỔI HỢP LỆ ĐƯỢC HỖ TRỢ:
    - docx  ->  pdf
    - doc   ->  pdf
    - txt   ->  pdf
    - txt   ->  docx (hoặc doc)
    - xlsx  ->  csv
    - xlsx  ->  json
    - xlsx  ->  pdf
    - png   ->  svg (Vector tracing via VTracer)
    - png   ->  jpg (hoặc jpeg)
    - png   ->  webp
    - jpg   ->  png
    - jpg   ->  webp
* options: [JSON string] Tùy chọn nâng cao theo từng loại:
    + Cho txt -> pdf:
        - "title": [string] Tiêu đề tài liệu PDF (mặc định: "Tài liệu").
    + Cho txt -> docx:
        - "title": [string] Tiêu đề tài liệu Word.
    + Cho xlsx -> csv:
        - "sheet_name": [string] Tên sheet cần xuất (mặc định: sheet đầu tiên).
    + Cho xlsx -> json:
        - "sheet_name": [string] Tên sheet cần xuất.
        - "all_sheets": [bool, true/false] Xuất tất cả các sheet thành multi-dict (mặc định: false).
    + Cho xlsx -> pdf:
        - "sheet_name": [string] Tên sheet.
        - "title": [string] Tiêu đề bảng tính (mặc định: "Bảng tính Excel").
    + Cho png -> svg (VTracer):
        - "colormode": "color" (giữ màu) hoặc "binary" (đen trắng) (mặc định: "color").
        - "mode": "spline" (mượt), "polygon" (đa giác), "pixel" (mặc định: "spline").
    + Cho png -> jpg, jpg -> webp:
        - "quality": [int, 1-100] (mặc định: 90-95).
        - "lossless": [bool, true/false] (chỉ cho webp).

4. GET /api/v1/jobs/{job_id}
--------------------------------------------------------------------------------
Dùng để: Theo dõi trạng thái tiến độ job và nhận link/key kết quả.
Params:
* Path param:
    - job_id: [string, UUID] ID của Job.
* Header:
    - Authorization: Tùy chọn (KHÔNG BẮT BUỘC - Bất kỳ client nào có job_id đều xem được tiến độ).
Output fields chính:
    - status: "queued" | "processing" | "completed" | "failed"
    - progress: 0 -> 100
    - output_key: "outputs/{job_id}/result.{ext}"
    - expires_at: Thời điểm hết hạn (TTL 3 phút đối với file kết quả, 5 phút đối với job failed).


--------------------------------------------------------------------------------
5. GET /api/v1/files/{job_id}/download
--------------------------------------------------------------------------------
Dùng để: Tải file kết quả.
Params:
* Path param:
    - job_id: [string, UUID] ID của Job.
* Header:
    - Authorization: Tùy chọn (KHÔNG BẮT BUỘC - Bất kỳ ai có job_id đều có thể tải file kết quả).
* Query params:
    - direct: [bool, true/false] (Mặc định: false)
        + direct=true: Tải trực tiếp stream binary file về máy client. Sau khi stream 100% thành công,
          server tự động xóa file trên R2 và xóa Job khỏi DB ngay lập tức (không cần chờ hết 3 phút).
          Nếu mạng đứt giữa chừng, file được giữ nguyên cho phép retry.
        + direct=false: Trả về JSON chứa presigned URL tải từ Cloudflare R2.
    - redirect: [bool, true/false] (Mặc định: false)
        + redirect=true: HTTP 307 Redirect trình duyệt trực tiếp sang R2 download link.

7. POST /api/v1/files/presigned-upload-url
--------------------------------------------------------------------------------
Dùng để: Tạo presigned PUT URL để client upload trực tiếp file lớn lên R2 (tránh qua FastAPI).
Body (JSON):
* key: [string, bắt buộc] Đường dẫn lưu trữ, ví dụ: "uploads/{job_id}/original.mp4".
* content_type: [string, tùy chọn] MIME type, ví dụ: "video/mp4", "image/png".
* expires_in: [int, 60 đến 86400, mặc định: 900] Thời hạn URL tính theo giây.


--------------------------------------------------------------------------------
8. POST /api/v1/files/presigned-download-url
--------------------------------------------------------------------------------
Dùng để: Tạo presigned GET URL để tải một key bất kỳ từ R2.
Body (JSON):
* key: [string, bắt buộc] Key file trên R2.
* expires_in: [int, 60 đến 86400, mặc định: 900].

9. POST /api/v1/payments/payos
--------------------------------------------------------------------------------
Dùng để: Tạo link thanh toán nâng cấp tài khoản qua PayOS.

* cancel_url: [string, bắt buộc] URL chuyển hướng khi người dùng hủy.
